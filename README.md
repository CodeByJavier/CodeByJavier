## Proyectos

**[Clon de la interfaz de GitHub](https://github.com/CodeByJavier/github-clone)** ·
[ver la demo](https://codebyjavier.github.io/github-clone/)

Reproducción de la página de inicio y la de crear repositorio, responsive, con HTML, CSS y
JavaScript. Sin frameworks, sin librerías y sin proceso de compilación. Los fragmentos comunes
se cargan con `fetch` para no duplicar marcado, los repositorios persisten en `localStorage`,
y el tema claro/oscuro se resuelve con un atributo en el `<html>` para que el botón pueda mandar
sobre la preferencia del sistema.

**[Pokédex](https://github.com/CodeByJavier/Pokedex)**
[ver la demo](https://codebyjavier.github.io/Pokedex/)

Una Pokédex interactiva construida con HTML, CSS y JavaScript puro (vanilla), que consume la PokeAPI para mostrar información de Pokémon en tiempo real.

su sitio de verdad: decenas de valores que cambian solos varias veces por segundo y que hay que

compradas.

En paralelo, afianzando JavaScript a fondo y aprendiendo a leer documentación técnica en lugar de
buscar la respuesta hecha.
